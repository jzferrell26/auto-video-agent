## Remotion

The Remotion packages this project installs (remotion, @remotion/cli and
@remotion/google-fonts, currently version 4.0.541) carry the Remotion License, not MIT.
Each package ships it as LICENSE.md. Read `node_modules/remotion/LICENSE.md` for the
version you actually install.

The Remotion license is between you and Remotion. This project's MIT license does not give
you any Remotion rights. The 4.0.541 license says you can use Remotion for free if you are:

- an individual
- a for-profit organization with up to 3 employees
- a non-profit or not-for-profit organization
- evaluating whether Remotion is a good fit, and not yet using it in a commercial way

Everyone else needs a Company License from Remotion. That license text also does not allow
copying or modifying Remotion code to sell, rent, license, relicense or sublicense your own
version of Remotion. Remotion also publishes
[license](https://www.remotion.dev/docs/license) and
[pricing](https://www.remotion.dev/docs/license/pricing) pages.

Terms change between versions. The 4.0.541 license says it will change slightly in
Remotion 5.0, and Remotion's website describes terms that take effect with 5.0.
Check the license file that ships with the version you install, and ask Remotion or your own
counsel if you are not sure which group you are in. Schools, universities and employers can
have their own rules, so check before using this template for class or client work.

# Getting help

Start with the [README](README.md) and [engine reference](engine/README.md).

For a reproducible bug, open a bug report. Include your operating system, Node.js version, exact command, expected result and a sanitized error excerpt. A tiny synthetic example is more useful than a full recording.

For a proposed improvement, open a feature request explaining the student workflow it would help. Course-specific questions belong in your course's own support channel. This repository does not include private course access or a support SLA.

Never attach `.env` files, client footage, full transcripts, account IDs or signed URLs. Use [private reporting](SECURITY.md) for vulnerabilities.
